# Notas de obra · cómo usar este kit con Claude Code

## 1. Instalar (una sola vez)
1. **Git para Windows**: https://git-scm.com/download/win (opciones por defecto).
2. **Node.js LTS**: https://nodejs.org (opciones por defecto).
3. **Claude** para escritorio: https://claude.ai/download. Inicia sesión y abre la pestaña **Code**.
4. Ten a mano tu cuenta de **GitHub**, tu cuenta de **Cloudflare** y tu clave de Anthropic (la misma de las otras apps).

## 2. Preparar la carpeta
Descomprime este zip en una carpeta fija, por ejemplo `Documentos\Apps\notas-obra`. Esa carpeta será el proyecto a partir de ahora: no la borres ni la muevas.

## 3. Publicar la fase 1
En Claude Code, abre la carpeta `notas-obra` y escribe:

> Lee CLAUDE.md y publica la fase 1 siguiendo el apartado «Primera publicación».

Te pedirá permiso para cada paso. Lo que harás tú:
- Aceptar el inicio de sesión de Cloudflare y de GitHub cuando se abra el navegador.
- Escribir en la terminal tu clave de Anthropic y el token de la app cuando te lo pida (no los pegues en el chat).
- Al final, abrir la app en el móvil y en el ordenador, y en Ajustes poner la URL del worker y el token.

Usa la app unos días y anota lo que quieras cambiar.

## 4. Construir la fase 2
Cuando quieras, en una conversación nueva de Claude Code:

> Lee CLAUDE.md y docs/FASE2.md y construye la fase 2. Enséñame cada parte funcionando antes de seguir con la siguiente.

Para correcciones sueltas, abre siempre una conversación nueva y pide el cambio concreto, por ejemplo:
> En el calendario, que el horario por defecto empiece a las 8:00.
